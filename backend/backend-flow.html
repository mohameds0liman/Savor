backend/src/

Request Lifecycle

Browser → MongoDB and back

● Entrypoint ● Middleware ● Routes ● Controllers ● Services ● Models ● Database

1 · Entrypoint

client
Browser / HTTP client
Sends GET /api/recipes or POST /api/recipes
server.ts
Express starts on :5000
Single entry. Listens for all incoming requests. Almost empty file.
app.ts
App registers all routes
app.use("/api", recipeRoutes)
app.use("/api", authRoutes)
app.use("/api", userRoutes)

2 · Middleware — runs before every controller

middlewares/auth.ts
Auth guard
Verifies JWT. If invalid → returns 401 immediately. Controller never fires.
middlewares/validation.ts
Body validation
Zod/Joi schema check. If shape is wrong → 400 early, no DB hit.
middlewares/error.ts
Global error handler
Catches anything thrown below. Returns consistent JSON error shape always.

3 · Routes — map URL to function, no logic

routes/recipe.routes.ts
Recipe endpoints
GET /recipes → getRecipes()
POST /recipes → createRecipe()
routes/auth.routes.ts
Auth endpoints
POST /login → login()
POST /register → register()
routes/user.routes.ts
User endpoints
GET /users/me → getMe()
PATCH /users/me → updateMe()

4 · Controllers — handle request, coordinate response, no DB knowledge

controllers/recipe.controller.ts
getRecipes() · createRecipe()
Reads req → calls service → returns res.json(). Never touches MongoDB directly.
controllers/auth.controller.ts
login() · register()
Reads credentials from req.body → calls authService → returns token
controllers/user.controller.ts
getMe() · updateMe()
Reads req.user set by auth middleware → delegates to userService

5 · Services — all business logic, Express-free

services/recipe.service.ts
getAllRecipes() · createRecipe()
Validate → check duplicates → generate slug → save to DB → return result
services/auth.service.ts
login() · register()
Hash password → create user → sign JWT via utils/jwt.ts → return token
services/user.service.ts
getUser() · updateUser()
Fetch from DB, format with utils/helpers.ts, return clean DTO

6 · Models — Mongoose schemas, talk to MongoDB

models/Recipe.ts
Recipe schema
name · description · image
Recipe.find() · Recipe.create()
models/User.ts
User schema
name · email · passwordHash · role
User.findOne() · User.create()
models/Organization.ts
Org schema
name · members · plan

7 · Database & config

config/db.ts
MongoDB via Mongoose
mongoose.connect() — reads URI from config/env.ts
config/env.ts
Environment config
Reads .env — MONGO_URI · JWT_SECRET · PORT · CLOUDINARY_KEY

Support layers — shared across the whole app

utils/jwt.ts
JWT helpers
signToken()
verifyToken()
utils/logger.ts
Logger
Structured request & error logging
utils/helpers.ts
Helpers
generateSlug()
formatDate()
capitalize()
types/
TypeScript types
RecipeDTO · UserDTO
AuthRequest — no logic, pure types
uploads/
File uploads
Static user-uploaded images if not on Cloudinary

Full request trace — POST /api/recipes

Browser → server.ts → app.ts → auth.ts → validation.ts → recipe.routes.ts → recipe.controller.ts → recipe.service.ts → Recipe.ts → MongoDB
↩ Response: MongoDB → Recipe.ts → recipe.service.ts → recipe.controller.ts → res.json() → Browser

backend/ · Express + TypeScript + MongoDB
